# AttendX — C++ Attendance Management System

AttendX is a console based attendance management system developed as part of my **Object Oriented Programming (OOP) course project**. It is built using C++ and demonstrates core OOP principles, file handling, and the Standard Template Library (STL).

## ✨ Features

- Add students with unique roll numbers
- Display registered students
- Mark students as present or absent
- Generate attendance reports with percentages
- Delete student records
- Save and load student and attendance data using file handling
- Preserve attendance records between program runs

## 📚 Concepts Used

- Classes and objects
- Encapsulation
- Inheritance
- Constructors
- Vectors and strings (STL)
- File handling
- Input validation

## 🛠️ Technologies Used

- C++
- Standard Template Library (STL)
- File handling (`fstream`)

## 🚀 How to Run

1. Clone this repository.
2. Compile `main.cpp` using a C++ compiler.
3. Run the generated executable.

### Compile using g++

```bash
g++ main.cpp -o AttendX
```

### Run on Windows

```powershell
.\AttendX.exe
```

## 🎯 Project Purpose

This project was developed to apply and strengthen my understanding of C++ and Object Oriented Programming through a practical application.

## 📝 Note

AttendX currently uses a console based interface and local text files for data storage. It is an educational project that can be extended with additional features in the future.
